# Фотофиксация обследования

Приложение для телефона и планшета: снимок на объекте, конструкция, марка, оси, этаж, дефект (ширина трещины), описание текстом или диктовкой, голосовая запись. Данные хранятся только на телефоне, приложение работает без интернета после первого открытия.

Адрес: https://aukurohtin-cyber.github.io/fotofix/

## Как пользоваться
1. Откройте адрес на телефоне один раз при наличии интернета.
2. Добавьте на главный экран: Android, Chrome: меню, «Установить приложение»; iPhone, Safari: «Поделиться», «На экран Домой».
3. На объекте: «Снять», выбор конструкции, осей, этажа, дефекта, описание или голос, «Сохранить и снять еще».
4. В офисе: «Передать», один файл ZIP (фото, голос, перечень для Excel). В «Справочнике обследователя»: страница объекта, раздел «Фото», «Загрузить с телефона».

Фото и записи в этот репозиторий не попадают: здесь только код приложения.
